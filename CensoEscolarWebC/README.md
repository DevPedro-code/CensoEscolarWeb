# CensoEscolarWeb

Aplicação web em React (Vite + React Bootstrap) para apresentar dados do Censo Escolar 2025 das Instituições de Ensino da Paraíba.

## Páginas

- **Home**: carrossel de imagens e cartões de informação.
- **Instituições Ensino**: tabela com as 10 IEs com mais matrículas (`qt_mat_bas`) da Paraíba.
